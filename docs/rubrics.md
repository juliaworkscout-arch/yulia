# Рубрикатор ПОВОД

Единый список рубрик для Telegram, Instagram и Threads — чтобы контент-план не превращался в хаос и было видно баланс тем.

## Основные направления (из ТЗ)

| Рубрика | Что это | Частота ориентировочно |
|---|---|---|
| 🆕 Новые заведения | Открытия кафе, баров, магазинов, шоурумов — стараемся быть одними из первых | по факту события, приоритет |
| 🏙 Городские новости | Инфраструктура, транспорт, события в городе, важное для минчан | по факту события |
| 🇧🇾 Белорусские бренды | Локальные бренды одежды, косметики, дизайна, еды | 1–2 раза в неделю |
| 📋 Подборки | Тематические списки мест/активностей («куда сходить на свидание», «где отметить ДР», «5 мест с летней верандой») | ежедневно/через день в Telegram, 4 раза в неделю в Instagram |
| 🧑‍🎨 Локальные проекты и ремесленники | Мастера, small-business, крафтовые истории, инициативы | 1 раз в неделю |
| 📆 Афиша/события | Концерты, ярмарки, маркеты, выставки, фестивали | по календарю событий |
| 💬 Личное/закулисье | Мнение редакции, самоирония про город, реакция на инфоповод | по ситуации, для вовлечения |

## Дополнительные форматы для вовлечения

- **Опросы/голосования** — «куда сходить в эти выходные», «за какой бар голосуем».
- **Вопрос к аудитории** — сбор UGC («киньте своё любимое место с видом на закат»).
- **Дайджест недели** — короткое саммари главных поводов недели (пятница/воскресенье).
- **Рубрика «Было — стало»** — переезды, ребрендинги, реновации заведений.

## Правило баланса (ориентир на неделю в Telegram, 15 постов)

- Новые заведения / городские новости — приоритетно, без фиксированной квоты (оперативность важнее графика).
- Подборки — 3–5 в неделю.
- Белорусские бренды — 2–3 в неделю.
- Локальные проекты/ремесленники — 1–2 в неделю.
- Вовлекающий формат (опрос/вопрос/дайджест) — 1–2 в неделю.

Итоговое распределение уточняется в `content-plan-telegram.md` и фиксируется в `calendar/content-calendar-template.csv`.
