# Финальный чек-лист перед публикацией

Прогонять по каждому посту непосредственно перед тем, как поставить его в очередь/опубликовать.

## Контент

- [ ] Пройден факт-чек (`fact-check-checklist.md`).
- [ ] Текст соответствует Tone of Voice (`tone-of-voice.md`): без канцелярита, без токсичной иронии, есть понятное действие для читателя.
- [ ] Одна мысль/один повод на пост — нет «каши» из нескольких несвязанных тем.
- [ ] Указаны конкретика: адрес, время работы, цена/диапазон цен, как забронировать/куда идти по ссылке.
- [ ] Заголовок/первая строка — цепляет и понятен без контекста (человек листает ленту, у нас 1–2 секунды).
- [ ] Для Telegram: текст ёмкий, без длинных полотен.
- [ ] Для Telegram: обращение к аудитории на «вы».
- [ ] В тексте нет мата, грубого сленга и слишком фамильярного тона.
- [ ] Нет орфографических и пунктуационных ошибок (перечитать вслух).
- [ ] Если пост рекламный/партнёрский — стоит пометка.

## Оформление

- [ ] Эмодзи расставлены точечно, не перегружают текст.
- [ ] Фото/видео есть, в хорошем качестве, соответствуют теме (не «сток» без связи с постом).
- [ ] Ссылки рабочие: перейти по каждой и убедиться, что она ведёт куда нужно.
- [ ] Для Telegram в конце поста стоят 1–3 релевантных хештега из `telegram-hashtag-navigation.md`.
- [ ] В Telegram-посте нет лишних тегов «на всякий случай» и не используется `#досуг`.
- [ ] Для карусели/подборки — порядок слайдов логичен, обложка цепляет, финальный слайд с призывом («сохрани», «поделись»).

## Технически

- [ ] Пост встаёт в нужный слот по сетке (`content-plan-telegram.md` / `content-plan-instagram-threads.md`), либо осознанно публикуется вне графика (горячий инфоповод).
- [ ] Указана рубрика/тег для внутренней аналитики.
- [ ] Публикация зафиксирована в `calendar/content-calendar-template.csv`.
- [ ] Для Threads — ссылка на подробности добавлена в первый комментарий сразу после публикации.
- [ ] Для сторис — стикер-ссылка/кнопка на Telegram работает и ведёт на нужный пост.

## После публикации

- [ ] Через 24–48 часов — снять метрики (охват, реакции, репосты/сохранения, переходы по ссылке) и занести в еженедельный отчёт.
- [ ] Если в посте была допущена ошибка — оперативно исправить и, если ошибка существенная, дать корректировку отдельным сообщением/в комментарии.
