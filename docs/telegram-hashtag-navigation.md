# Telegram-навигация по хештегам

Единая система хештегов для Telegram-канала `@povodminsk`. Используем для навигации, закрепа и поиска по каналу.

## Главный принцип

Под каждым Telegram-постом ставим **1–3 релевантных хештега**:

- один основной тег по теме;
- при необходимости один дополнительный тег по сценарию/формату;
- не ставим весь список тегов сразу.

Пример:

```text
#кафе #свидание
```

или:

```text
#бренды #одежда
```

## Рекомендованная структура тегов

### Бренды

- `#бренды` — общий тег для локальных и белорусских брендов.
- `#одежда` — одежда, дропы, капсулы, шоурумы.
- `#обувь` — обувные бренды, коллаборации, новые модели.
- `#сумки` — сумки, аксессуары к образам, локальные изделия.
- `#аксессуары` — украшения, очки, носки, мелкие детали образа.

### Места

- `#рестораны` — рестораны, ужины, места с полноценной кухней.
- `#кафе` — кофейни, завтраки, десерты, небольшие городские места.
- `#свидание` — места и сценарии для свиданий.
- `#открытия` — новые места и проекты.
- `#новости` — важное по городу.

### Развлечения и досуг

- `#развлечения` — активности, выставки, квизы, мастер-классы и идеи, чем заняться в городе.
- `#спорт` — пробежки, тренировки, йога, веломаршруты, водные активности.
- `#кино` — премьеры, артхаус, киноафиши, спецпоказы.
- `#музыка` — концерты, клубные программы, диджей-сеты, музыкальные события.

> `#досуг` не используем как основной тег: он слишком близок к `#развлечения` и размывает навигацию. Если нужно обозначить свободное время/активности, выбираем `#развлечения`.

### Достопримечательности и гид для гостей

- `#достопримечательности` — основные места Минска, которые стоит увидеть.
- `#пешеходные` — прогулочные маршруты и интересные улицы.
- `#музеи` — музеи, галереи и выставочные пространства с кратким описанием.
- `#фотолокации` — точки для красивых фото и контента.

> В Telegram лучше использовать `#фотолокации`, а не `#фото-локации`: дефис может разорвать кликабельный хештег.

## Как выбирать тег под пост

| Тип поста | Теги |
|---|---|
| Новый ресторан | `#открытия #рестораны` |
| Новая кофейня | `#открытия #кафе` |
| Городская новость | `#новости` |
| Подборка мест для свидания | `#свидание #кафе` или `#свидание #рестораны` |
| Белорусский бренд одежды | `#бренды #одежда` |
| Бренд аксессуаров | `#бренды #аксессуары` |
| Маркет локальных брендов | `#бренды #аксессуары` или `#бренды #одежда` |
| Активность на воде / йога / квиз | `#развлечения` |
| Пробежка / йога / веломаршрут | `#спорт #развлечения` |
| Концерт / диджей-сет | `#музыка` |
| Кинопоказ | `#кино` |
| Маршрут для гостей Минска | `#достопримечательности #пешеходные` |
| Музей или галерея | `#музеи #достопримечательности` |
| Точка для красивых фото | `#фотолокации #пешеходные` |

## Правило для автора

Перед публикацией проверяем:

- [ ] В конце поста стоят 1–3 релевантных хештега.
- [ ] Нет лишних тегов «на всякий случай».
- [ ] Если есть выбор между `#развлечения` и `#досуг`, выбираем `#развлечения`.
- [ ] Тег соответствует реальному содержанию поста.
