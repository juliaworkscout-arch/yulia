# Навык: Instagram-подборка для ПОВОД

Использовать каждый раз, когда нужно сделать подборку для Instagram: карусель из 11 слайдов, текст для карточек, caption и при необходимости сторис-тизер.

## Когда включать навык

Если запрос звучит примерно так:

- «сделай подборку в Instagram»;
- «нужна карусель»;
- «подборка мест»;
- «адаптируй это для инсты»;
- «сделай слайды/обложку/caption».

## Главная задача Instagram-подборки

Подборка должна быть:

- визуально понятной;
- сохраняемой;
- полезной в конкретной ситуации: свидание, день рождения, выходные, завтрак, подарок, прогулка;
- написанной в стиле ПОВОД: как совет подруге, без сухой афиши.

## Приоритетный регламент

Пост-подборка в Instagram всегда состоит из **11 слайдов**:

1. **Слайд 1 — обложка**.
2. **Слайды 2–10 — локации/идеи**.
3. **Слайд 11 — заключительный CTA-слайд**.

Если пользователь прислал другое количество мест, всё равно ориентироваться на эту структуру:

- для 9 мест — по одному месту на слайды 2–10;
- если мест меньше 9 — предупредить, что для полной карусели нужно добрать пункты;
- если мест больше 9 — предложить сократить до 9 или сделать вторую часть.

## Tone of Voice и стоп-слова

Стиль: простой, живой язык, как общение с подружкой, но аккуратно оформленный.

Запрещено использовать:

- оборот «не X, а Y» в любых вариациях;
- фразы-клише: «Это не просто X, а...», «Тот случай, когда...», «Это не про..., это про...», «Спойлер: ...»;
- рваные фразы из 1–2 слов ради драматичности;
- конструкции с повтором предлога «без» в стиле «Без слов. Без восторгов»;
- ИИ-метафоры, клише и канцеляризмы: «настоящая жемчужина», «кусочек Италии в центре города», «атмосфера комфорта», «гастрономический рай», «подарит вам незабываемые эмоции» и похожие формулировки.
- ИИ-фразы про закаты, воду и отдых: «Никакой спешки — только шум волн», «городской шум на паузу», «место, где время замедляется», «перезагрузка для души».
- слово «идеальный» в подборках: вместо высокой оценки давать конкретную пользу или ситуацию.
- одинаковые прилагательные по кругу: особенно «отличный», «классный», «уютный», «атмосферный», «стильный». Если слово повторяется в подборке несколько раз, заменить часть повторов на более точные описания.

Перед выдачей финального текста проверить, что этих конструкций нет, а соседние слайды не начинаются одинаково.

## Как переписывать вместо клише

Сначала назвать конкретную деталь, потом пользу для читателя:

- вместо «Никакой спешки — только шум волн» → «Сюда едут за водой, ветром и закатом над Минским морем»;
- вместо «городской шум на паузу» → «После работы здесь можно посидеть у воды и проводить солнце»;
- вместо «идеальное место для свидания» → «Подойдёт для спокойного свидания: вид на воду, мало лишнего шума, удобно приехать к вечеру»;
- вместо «отличная локация» → «Есть терраса у воды / удобный спуск / вид на закат / можно взять напитки с собой».

## Что нужно получить от пользователя

Если данных не хватает, сначала попросить уточнить:

1. Тема подборки.
2. Целевая ситуация: для кого/зачем подборка.
3. Список 9 мест/брендов/событий для слайдов 2–10.
4. По каждому пункту: название, адрес, Instagram-ник, цена/диапазон, ключевая фишка, источник.
5. Для заведений: работает ли заявленная терраса/веранда и актуально ли меню, если в тексте называются конкретные блюда или напитки.
6. Фото/видео или ссылки на визуалы из открытых источников.
7. Нужен ли сторис-тизер для перегона в Telegram.

## Формула результата

### 1. Слайд 1 — обложка

Дать 3–5 вариантов связки «заголовок + подзаголовок».

```
[жирная строка / главная тема]
[подзаголовок / продолжение мысли]
```

Правила обложки:

- жирная строка — шрифт **Kreadon**;
- подзаголовок — **Montserrat Semibold**;
- жирная строка максимум 2 строки;
- подзаголовок максимум 2 строки;
- заголовок и подзаголовок должны дополнять друг друга, а не повторять одну мысль;
- на обложке в одном и том же месте должен быть водяной знак с логотипом ПОВОД сверху.

### 2. Слайды 2–10 — локация / идея

На каждый пункт:

```
[Название]
[1–3 короткие строки: что это, почему сюда идти, кому подойдёт]
📍 [район/адрес]
[@instagram_handle, если нужен на карточке]
```

Правила для слайдов:

- использовать готовый шаблон ПОВОД;
- не менять размеры шрифтов, фирменные цвета плашек и текста;
- визуалы должны быть качественными, актуальными и из открытых источников;
- не использовать афиши, картинки с чужими плашками, логотипами или текстом;
- если визуал вызывает сомнение — отметить «нужно согласовать фото».

### 3. Слайд 11 — заключительный CTA

```
[Короткий CTA: сохранить подборку, отправить другу, написать свои места в комментариях]
```

### 4. Caption

Короткое описание к посту:

- 1–2 предложения, почему эта подборка актуальна;
- логичные абзацы;
- умеренно добавить эмодзи;
- после короткого введения дать список-дублирование названий со слайдов + Instagram-ники каждого места;
- CTA: сохранить/отправить/написать свои места в комментариях;
- не перегружать текст.

### 5. Сторис-тизер, если нужен

1–3 коротких сторис:

- крючок;
- интрига/визуал;
- ссылка или призыв перейти в Telegram.

## Обязательные правила

- Не добавлять места/факты без источника.
- Если по месту не хватает адреса/цены/фишки — пометить «нужно уточнить».
- Если терраса, веранда или конкретные позиции меню не подтверждены на момент публикации — пометить «нужно уточнить/позвонить» или заменить место.
- Если у заведения временная смена меню, упоминать это коротко и без драматизации, не обещая недоступные позиции.
- Если нет Instagram-ника места — пометить «нужно уточнить Instagram».
- Если нет подходящего визуала — пометить «нужно подобрать/согласовать фото».
- Не делать описание слишком длинным: Instagram-подборка должна читаться быстро.
- Не копировать Telegram-пост один в один — адаптировать под слайды.
- Каждый слайд должен отвечать на вопрос: «почему это стоит сохранить?».
- Соблюдать стоп-слова и запрещённые конструкции из раздела Tone of Voice.
- После написания подборки пройтись по всем слайдам и заменить повторы: одинаковые начала, одинаковые прилагательные, одинаковый ритм.

## Что отдавать

По умолчанию:

1. 5 вариантов заголовка для обложки.
2. Тексты для слайдов 2–10.
3. Текст для слайда 11.
4. Caption.
5. Сторис-тизер.
6. Список фактов, которые нужно проверить перед публикацией.
