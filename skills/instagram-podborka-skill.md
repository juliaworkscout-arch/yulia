# Навык: Instagram-подборка для ПОВОД

Использовать каждый раз, когда нужно сделать подборку для Instagram: карусель, caption, сторис-тизер или адаптацию Telegram-подборки в Instagram.

## Когда включать навык

Если запрос звучит примерно так:

- «сделай подборку в Instagram»;
- «нужна карусель»;
- «подборка мест»;
- «адаптируй это для инсты»;
- «сделай слайды/обложку/caption».

## Главная задача Instagram-подборки

Подборка должна быть:

- визуально понятной;
- сохраняемой;
- полезной в конкретной ситуации: свидание, день рождения, выходные, завтрак, подарок, прогулка;
- написанной в стиле ПОВОД: как совет подруге, без сухой афиши.

## Что нужно получить от пользователя

Если данных не хватает, сначала попросить уточнить:

1. Тема подборки.
2. Целевая ситуация: для кого/зачем подборка.
3. Список мест/брендов/событий.
4. По каждому пункту: название, адрес, цена/диапазон, ключевая фишка, источник.
5. Сколько слайдов нужно.
6. Нужен ли сторис-тизер для перегона в Telegram.

## Формула результата

### 1. Обложка

Дать 3–5 вариантов короткого заголовка:

```
[живой крючок]
[подзаголовок: 5 мест / куда сходить / сохраняй]
```

### 2. Слайды

На каждый пункт:

```
[Название]
[1–2 короткие строки: почему это место в подборке, какой вайб, кому подойдёт]
📍 [район/адрес]
```

### 3. Финальный слайд

```
Сохраняй, чтобы не потерять 📌
Отправь тому, с кем пойдёшь
Больше поводов — в Telegram
```

### 4. Caption

Короткое описание к посту:

- 1–2 предложения, почему эта подборка актуальна;
- CTA: сохранить/отправить/перейти в Telegram;
- без длинного полотна текста.

### 5. Сторис-тизер, если нужен

1–3 коротких сторис:

- крючок;
- интрига/визуал;
- ссылка или призыв перейти в Telegram.

## Обязательные правила

- Не добавлять места/факты без источника.
- Если по месту не хватает адреса/цены/фишки — пометить «нужно уточнить».
- Не делать описание слишком длинным: Instagram-подборка должна читаться быстро.
- Не копировать Telegram-пост один в один — адаптировать под слайды.
- Каждый слайд должен отвечать на вопрос: «почему это стоит сохранить?».

## Что отдавать

По умолчанию:

1. 5 вариантов заголовка для обложки.
2. Тексты для слайдов.
3. Финальный слайд.
4. Caption.
5. Сторис-тизер.
6. Список фактов, которые нужно проверить перед публикацией.

## Место для шаблонов Юли

Когда будут присланы финальные шаблоны, вставить их сюда и считать их приоритетнее общей формулы.

```
[сюда добавить шаблон Instagram-подборки]
```
