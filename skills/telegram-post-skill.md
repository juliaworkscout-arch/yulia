# Навык: Telegram-пост для ПОВОД

Использовать каждый раз, когда нужно написать, переписать или докрутить пост для Telegram-канала `@povodminsk`.

## Когда включать навык

Если запрос звучит примерно так:

- «напиши пост в телеграм»;
- «сделай текст для канала»;
- «адаптируй инфоповод для ПОВОД»;
- «перепиши в нашем стиле»;
- «вот источник/новость/место, сделай пост».

## Главная интонация

Пишем так, будто советуем подруге:

- живо, коротко, без официоза;
- не продаём, а делимся находкой;
- даём конкретику: где, когда, сколько стоит, что попробовать, с кем идти;
- финал строит комьюнити: вопрос, реакции, «отправляйте тому, с кем пойдёте».

## Что нужно получить от пользователя

Если данных не хватает, сначала попросить уточнить:

1. Инфоповод/тема.
2. Проверенный источник.
3. Факты: адрес, дата, время, цена, ссылка/бронь.
4. Что важно подчеркнуть: вайб, польза, необычная деталь, ограниченность предложения.
5. Есть ли это реклама/бартер/партнёрский материал.

## Формула результата

```
[Эмодзи] [живой заголовок-крючок]

[1 абзац: что случилось/что появилось]

[1 абзац: почему это повод — зачем идти/пробовать/сохранять]

📍 Где: [адрес]
🕒 Когда: [дата/время, если есть]
💳 Прайс: [цена, если есть]
🔗 [ссылка/бронь, если есть]

[дружеский финал: вопрос, реакция, «отправляйте тому...»]
```

## Обязательные правила

- Не добавлять факты, которых нет во вводных.
- Если нет источника — отметить, что перед публикацией нужен факт-чек.
- Не использовать канцелярит: «состоится», «мероприятие пройдёт», «посетителям будет предложено».
- Не писать слишком длинно: Telegram-пост должен легко читаться с телефона.
- Если текст выглядит слишком рекламно — сделать его более честным и редакционным.

## Что отдавать

По умолчанию:

1. 3 варианта заголовка.
2. 1 готовый Telegram-пост.
3. 2 варианта финального CTA/вопроса.
4. Короткий список «что нужно проверить перед публикацией», если есть пробелы в фактах.
