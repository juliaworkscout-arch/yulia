# Навык: Telegram-пост для ПОВОД

Использовать каждый раз, когда нужно написать, переписать или докрутить пост для Telegram-канала `@povodminsk`.

## Когда включать навык

Если запрос звучит примерно так:

- «напиши пост в телеграм»;
- «сделай текст для канала»;
- «адаптируй инфоповод для ПОВОД»;
- «перепиши в нашем стиле»;
- «вот источник/новость/место, сделай пост».

## Главная интонация

Пишем так, будто советуем подруге:

- живо, коротко, без официоза;
- делимся находкой и полезными деталями без рекламного давления;
- даём конкретику: где, когда, сколько стоит, что попробовать, с кем идти;
- финал строит комьюнити: вопрос, реакции, «отправляйте тому, с кем пойдёте».
- обращаемся к аудитории на «вы»;
- не используем мат и грубый сленг.

## Что нужно получить от пользователя

Если данных не хватает, сначала попросить уточнить:

1. Инфоповод/тема.
2. Проверенный источник.
3. Факты: адрес, дата, время, цена, ссылка/бронь.
4. Что важно подчеркнуть: вайб, польза, необычная деталь, ограниченность предложения.
5. Есть ли это реклама/бартер/партнёрский материал.
6. Какие хештеги подходят из навигации, если пользователь уже выбрал их.
7. Тип контента, если пользователь его знает: анонс, подборка, опрос, мем, вовлекающий пост, анонс + опрос.

## Формула результата

```
[Эмодзи] [живой заголовок-крючок]

[1 абзац: что случилось/что появилось]

[1 абзац: почему это повод — зачем идти/пробовать/сохранять]

📍 Где: [адрес]
🕒 Когда: [дата/время, если есть]
💳 Прайс: [цена, если есть]
🔗 [ссылка/бронь, если есть]

[дружеский финал: вопрос, реакция, «отправляйте тому...»]

[1–3 релевантных хештега из навигации]
```

## Обязательные правила

- Не добавлять факты, которых нет во вводных.
- Если нет источника — отметить, что перед публикацией нужен факт-чек.
- Не использовать канцелярит: «состоится», «мероприятие пройдёт», «посетителям будет предложено».
- Не писать слишком длинно: Telegram-пост должен легко читаться с телефона.
- Если текст выглядит слишком рекламно — сделать его более честным и редакционным.
- Не обращаться к аудитории на «ты»; использовать «вы», «сохраняйте», «пишите», «делитесь».
- Не использовать мат, грубый и лишний молодёжный сленг: «дропаем», «вайбим», «залетаем» и похожие слова заменять на простые человеческие формулировки.
- Не использовать ИИ-клише: «никакой спешки — только шум волн», «городской шум на паузу», «место, где время замедляется», «перезагрузка для души».
- Не использовать шаблонные мемные заходы: «режим плед, чай и не трогайте меня», «Минск включил режим...», «ну всё понятно», если это звучит фейково и не похоже на живую редакционную фразу.
- Не использовать слово «идеальный» в подборках и рекомендациях. Заменять на конкретику: «подойдёт для...», «удобно, если...», «можно зайти после...».
- Проверять повторы прилагательных. Если в тексте несколько раз встречаются «отличный», «классный», «уютный», «стильный», заменить часть на более точные описания.
- Не использовать одинаковые конструкции в соседних абзацах: менять начало предложений и ритм текста.
- В конце каждого поста добавлять 1–3 релевантных хештега из Telegram-навигации.
- В постах про заведения, городские места и локации третьим тегом добавлять район/зону, если она понятна по адресу.
- Не использовать `#досуг`: вместо него выбирать `#развлечения`, чтобы не дублировать смысл.

## Telegram-навигация по хештегам

Основные теги:

- Бренды: `#бренды`, `#одежда`, `#обувь`, `#сумки`, `#аксессуары`.
- Места: `#рестораны`, `#кафе`, `#свидание`, `#открытия`, `#новости`.
- Развлечения и досуг: `#развлечения`, `#спорт`, `#кино`, `#музыка`.
- Достопримечательности и гид для гостей: `#достопримечательности`, `#пешеходные`, `#музеи`, `#фотолокации`.
- Районы и зоны: `#центр`, `#немига`, `#октябрьская`, `#зыбицкая`, `#комаровка`, `#минскмир`, `#восток`, `#уручье`, `#лебяжий`, `#зелёныйлуг`, `#серебрянка`, `#лошица`, `#малиновка`, `#каменнаягорка`, `#сухарево`, `#чижовка`.

`#фото-локации` не использовать: в Telegram дефис может разорвать хештег. Вместо него ставить `#фотолокации`.
Старые теги, которых нет в актуальном закрепе, не использовать: `#ивенты`, `#маркеты`, `#афиша`.

Правило: ставить только теги, которые реально помогают найти пост. Обычно достаточно 1–2 тегов, максимум 3.

## Виды Telegram-контента

- Анонс мероприятия: спорт, тусовка, мастер-класс, концерт, фестиваль, маркет.
- Подборка: заведения, выставки, одежда, прогулки, фото-точки. Усиливать через общую боль/сценарий, а не сухую тему.
- Компактная подборка: короткая подводка + список в цитатном блоке, где каждый пункт выглядит как `Название — 2–6 слов`.
- Опрос: быстрый вопрос с простыми вариантами ответа.
- Вовлечение + диалог: просим поделиться местами, планами, опытом или найти компанию в комментариях.
- Мем: лёгкий узнаваемый пост без токсичности.
- Фото/видео + короткая подпись: быстрый эмоциональный формат.
- Анонс + опрос: событие плюс вопрос, кто планирует идти.

## Что отдавать

По умолчанию:

1. 3 варианта заголовка.
2. 1 готовый Telegram-пост.
3. 2 варианта финального CTA/вопроса.
4. Рекомендованные хештеги.
5. Короткий список «что нужно проверить перед публикацией», если есть пробелы в фактах.

```

```
