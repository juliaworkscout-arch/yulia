# Шаблон Instagram-подборки (карусель 11 слайдов)

## Регламент

- Карусель состоит из **11 слайдов**.
- Слайд 1 — обложка.
- Слайды 2–10 — локации/идеи.
- Слайд 11 — заключительный CTA.
- Тон: советуем подруге, живо и просто, без клише и канцелярита.
- Запрещены обороты «не X, а Y», «Тот случай, когда...», «Спойлер: ...», «Это не про..., это про...», «Это не просто X, а...».
- В подборках не используем слово «идеальный».
- Убираем ИИ-клише вроде «никакой спешки — только шум волн», «городской шум на паузу», «место, где время замедляется».
- Следим, чтобы в слайдах не повторялись одни и те же прилагательные: «отличный», «классный», «уютный», «атмосферный», «стильный».

## Слайд 1 — обложка

```
[Жирная строка / главная тема — Kreadon, максимум 2 строки]
[Подзаголовок — Montserrat Semibold, максимум 2 строки]
```

Пример логики:

```
Строим планы на лето
Что нужно успеть?
```

Правила:

- заголовок и подзаголовок дополняют друг друга;
- текст не превращает обложку в «газету»;
- водяной знак логотипа ПОВОД стоит сверху в одном и том же месте;
- если тема не помещается, переформулировать без потери смысла или вынести на согласование.

## Слайды 2–10 — локации / идеи

Один слайд = одно место или одна идея.

```
[Название заведения/места]
[1–3 короткие строки: что это, зачем идти, кому подойдёт]
📍 [район/адрес]
[@instagram_handle, если нужен на карточке]
```

## Слайд 11 — заключительный CTA

```
Сохраняйте подборку 📌
И делитесь в комментариях своими спотами
```

## Визуальный чек-лист

- [ ] Фото хорошего качества.
- [ ] Фото актуальные.
- [ ] Фото взяты из открытых источников или согласованы.
- [ ] Нет чужих плашек, логотипов, текста, афиш.
- [ ] Водяной знак ПОВОД стоит на обложке сверху в нужном месте.
- [ ] Размеры шрифтов, фирменные цвета плашек и текста не изменены.

## Текстовый чек-лист

- [ ] Все места прошли факт-чек (`../docs/fact-check-checklist.md`).
- [ ] У каждого места есть название, адрес и Instagram-ник.
- [ ] В тексте нет запрещённых конструкций и клише.
- [ ] В тексте нет слова «идеальный».
- [ ] Нет водно-закатных ИИ-клише вроде «шум волн», «городской шум на паузу», «время замедляется».
- [ ] Слайды не начинаются одинаково и не повторяют одну конструкцию.
- [ ] Прилагательные разнообразные и точные, «отличный» не используется как универсальная оценка.
- [ ] Обложка цепляет и читается в маленьком превью.
- [ ] Заголовок и подзаголовок на обложке не длиннее 2 строк каждый.
- [ ] Есть финальный слайд с призывом к действию
- [ ] Caption не перегружен и содержит список мест + Instagram-ники.
