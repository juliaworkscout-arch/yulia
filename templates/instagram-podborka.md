# Шаблон Instagram-подборки (карусель)

## Слайд 1 — обложка

```
[Заголовок-крючок крупным шрифтом, например: "ГДЕ ОТМЕТИТЬ ДР В МИНСКЕ, ЧТОБЫ ЗАПОМНИЛОСЬ"]
[Подзаголовок мельче: "5 мест / свайпай →"]
```

## Слайды 2–N — по одному объекту на слайд

```
[Название заведения/места]
[1–2 короткие строки сути: атмосфера + что берём/делаем там]
📍 [район/адрес]
```

## Финальный слайд — призыв к действию

```
Сохраняй, пригодится 📌
Больше поводов и подробности — в Telegram (ссылка в шапке)
```

## Описание к посту (caption)

```
[Заголовок-крючок, можно с эмодзи]

[1–2 предложения контекста: почему эта подборка сейчас актуальна]

Листай карусель → сохраняй → делись с тем, кому пригодится

Полная версия с деталями — в нашем Telegram (ссылка в шапке профиля)

#минск #поводминск #[тематические хэштеги под подборку]
```

## Чек-лист перед сдачей на согласование (за сутки до публикации)

- [ ] Все места из факт-чека (`../docs/fact-check-checklist.md`)
- [ ] Фото/видео по каждому пункту — в едином визуальном стиле
- [ ] Обложка цепляет и читаема даже в маленьком превью
- [ ] Есть финальный слайд с призывом к действию
- [ ] Caption адаптирован под Instagram (короче, чем в Telegram), есть ссылка на Telegram
