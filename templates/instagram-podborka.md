# Шаблон Instagram-подборки (карусель 11 слайдов)

## Регламент

- Карусель состоит из **11 слайдов**.
- Слайд 1 — обложка.
- Слайды 2–10 — локации/идеи.
- Слайд 11 — заключительный CTA.
- Тон: советуем подруге, живо и просто, без клише и канцелярита.
- Запрещены обороты «не X, а Y», «Тот случай, когда...», «Спойлер: ...», «Это не про..., это про...», «Это не просто X, а...».
- В подборках не используем слово «идеальный».
- Убираем ИИ-клише вроде «никакой спешки — только шум волн», «городской шум на паузу», «место, где время замедляется».
- Следим, чтобы в слайдах не повторялись одни и те же прилагательные: «отличный», «классный», «уютный», «атмосферный», «стильный».
- Следим, чтобы в слайдах не повторялись одни и те же конструкции: «хороший вариант», «подойдёт для тех», «можно заглянуть», «если хочется...».

## Слайд 1 — обложка

```
[Жирная строка / главная тема — Kreadon, максимум 2 строки]
[Подзаголовок — Montserrat Semibold, максимум 2 строки]
```

Пример логики:

```
Строим планы на лето
Что нужно успеть?
```

Правила:

- заголовок и подзаголовок дополняют друг друга;
- текст не превращает обложку в «газету»;
- водяной знак логотипа ПОВОД стоит сверху в одном и том же месте;
- если тема не помещается, переформулировать без потери смысла или вынести на согласование.

## Слайды 2–10 — локации / идеи

Один слайд = одно место или одна идея.

```
[Название заведения/места]
[1–3 короткие строки: что это, зачем идти, кому подойдёт]
📍 [район/адрес]
[@instagram_handle, если нужен на карточке]
```

### Для подборок с напитками

Текст может быть чуть плотнее, чем в обычной подборке. Важно не писать общими словами, а перечислять конкретные напитки.

```
[Название]
[Адрес — под названием или в плашке]

[3–5 предложений: какие напитки есть, 3–5 конкретных позиций из меню, есть ли терраса/посадка/особенность, зачем туда идти]
```

Правила:

- не дублируем адрес в абзаце, если он уже есть в плашке;
- не пишем просто «освежающие напитки» — называем вкусы;
- не повторяем «для жаркого дня» на каждом слайде;
- если есть терраса, упоминаем её как конкретную причину только после проверки, что она сейчас работает;
- если меню меняется или часть позиций временно недоступна, не обещаем конкретные коктейли без подтверждения и добавляем короткое предупреждение в текст;
- текст должен заполнять карточку, но не превращаться в длинный caption.

## Слайд 11 — заключительный CTA

```
Сохраняйте подборку 📌
И делитесь в комментариях своими спотами
```

## Описание к посту (caption)

Важно: начало caption не должно повторять текст с обложки. Если на обложке вопрос «куда идти...», в описании начинаем с ситуации, настроения или пользы подборки.

```
[Короткое введение: почему собрали эту подборку и кому она пригодится]

[Логичный второй абзац, если нужен]

В подборке:
1. [Название] — @[instagram_handle]
2. [Название] — @[instagram_handle]
3. [Название] — @[instagram_handle]
4. [Название] — @[instagram_handle]
5. [Название] — @[instagram_handle]
6. [Название] — @[instagram_handle]
7. [Название] — @[instagram_handle]
8. [Название] — @[instagram_handle]
9. [Название] — @[instagram_handle]

Сохраняйте, чтобы не искать в последний момент 💌
И пишите в комментариях, какие места добавили бы вы.
```

## Сторис-подводка к подборке

К каждой подборке обязательно добавляем текст для **1 сторис-подводки**. Команда сама снимает, редактирует и выкладывает сторис; от автора нужен только текст.

Формат выдачи:

```text
текст для сторис (что проговаривать): [1–3 живые фразы, которые можно сказать на камеру]
Текст для оформления (что прописывать): [короткая надпись на экране / стикере]
```

Правила:

- сторис должна подводить к теме подборки и давать причину открыть пост;
- текст для проговаривания пишем естественно, как для видео с лица команды;
- текст для оформления делаем коротким, чтобы он читался на экране;
- не дублируем caption целиком.

## Визуальный чек-лист

- [ ] Фото хорошего качества.
- [ ] Фото актуальные.
- [ ] Фото взяты из открытых источников или согласованы.
- [ ] Нет чужих плашек, логотипов, текста, афиш.
- [ ] Водяной знак ПОВОД стоит на обложке сверху в нужном месте.
- [ ] Размеры шрифтов, фирменные цвета плашек и текста не изменены.

## Текстовый чек-лист

- [ ] Все места прошли факт-чек (`../docs/fact-check-checklist.md`).
- [ ] У каждого места есть название, адрес и Instagram-ник.
- [ ] Для мест с террасой/верандой проверено, что посадка на улице сейчас работает.
- [ ] Для подборок с напитками проверено актуальное меню и наличие конкретных позиций.
- [ ] В тексте нет запрещённых конструкций и клише.
- [ ] В тексте нет слова «идеальный».
- [ ] Нет водно-закатных ИИ-клише вроде «шум волн», «городской шум на паузу», «время замедляется».
- [ ] Слайды не начинаются одинаково и не повторяют одну конструкцию.
- [ ] Прилагательные разнообразные и точные, «отличный» не используется как универсальная оценка.
- [ ] Нет повторяющихся универсальных фраз вроде «хороший вариант» и «подойдёт для тех».
- [ ] Обложка цепляет и читается в маленьком превью.
- [ ] Заголовок и подзаголовок на обложке не длиннее 2 строк каждый.
- [ ] Есть финальный слайд с призывом к действию
- [ ] Caption не перегружен и содержит список мест + Instagram-ники.
- [ ] Есть блок сторис-подводки: что проговаривать и что прописывать на экране.
