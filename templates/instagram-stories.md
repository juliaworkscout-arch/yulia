# Шаблон сторис (перегон трафика в Telegram)

## Логика

1 сторис = тизер инфоповода + понятный путь в Telegram, где вся подробная информация.

## Структура

**Кадр 1 — крючок**
```
[Короткая фраза-интрига: "Минск, у нас открытие 👀" / "Это надо знать до выходных"]
```

**Кадр 2 (опционально) — деталь/визуал**
```
[Фото/видео места или инфоповода, минимум текста]
```

**Кадр 3 — призыв к действию + ссылка**
```
[Короткая подпись: "Все детали и адрес — по ссылке"]
[Стикер-ссылка на конкретный пост в Telegram]
```

## Чек-лист

- [ ] Инфоповод прошёл факт-чек, ссылка на Telegram-пост с деталями уже опубликована
- [ ] Стикер-ссылка добавлен и ведёт именно на нужный пост (проверено переходом)
- [ ] Текста минимум, акцент на визуал и понятный призыв
- [ ] Стиль (шрифты/цвета) соответствует общему визуалу профиля
