# Шаблоны постов для Telegram

## Общая формула поста ПОВОД

Пишем так, будто советуем подруге, но обращаемся к аудитории на «вы»: «смотрите, что нашли, вот почему это может пригодиться, вот куда идти, вот сколько стоит, а дальше решайте, с кем пойдёте».

Правила текста:

- ёмко и кратко;
- свободный, простой и лёгкий стиль;
- без мата и грубого сленга;
- обращение на «вы»;
- в конце — понятное действие для аудитории.

```
[Эмодзи] [Короткий живой заголовок]

[1 абзац: что случилось/что появилось — без официоза, с ощущением находки]

[1 абзац: почему это повод — что попробовать, за чем идти, какой вайб, кому подойдёт]

[Конкретика: адрес / дата / цена / ссылка / бронь]

[Дружеский финал: вопрос, призыв отправить другу, мини-голосование реакциями]

[1–3 релевантных хештега из навигации]
```

Правило: в конце почти всегда должно быть маленькое действие — сохранить, отправить, выбрать реакцию, написать в комментариях или перейти по ссылке.
После финала добавляем 1–3 хештега для навигации по каналу.

## Навигационные хештеги

Бренды: `#бренды`, `#одежда`, `#обувь`, `#сумки`, `#аксессуары`.

Места: `#рестораны`, `#кафе`, `#свидание`.

Развлечения и досуг: `#развлечения`, `#спорт`, `#кино`, `#музыка`.

Достопримечательности и гид для гостей: `#достопримечательности`, `#пешеходные`, `#музеи`, `#фотолокации`.

`#досуг` не используем: он дублирует `#развлечения` и размывает навигацию.
`#фото-локации` не используем: в Telegram дефис может разорвать хештег, поэтому ставим `#фотолокации`.
Старые теги, которых нет в актуальном закрепе, не используем: `#новости`, `#ивенты`, `#маркеты`, `#афиша`, `#открытия`.

## Виды контента

- Анонс мероприятия: спорт / тусовка / мастер-класс / концерт / фестиваль / маркет.
- Подборка: заведения / выставки / одежда / маршруты / фото-точки.
- Опрос: быстрый вопрос для вовлечения.
- Вовлечение + диалог: комментарии, планы, места от подписчиков, поиск компании.
- Мем: лёгкий узнаваемый пост.
- Фото/видео + короткая подпись: настроение, погода, реакция редакции.
- Анонс + опрос: событие плюс вопрос, кто планирует идти.

## 🆕 Новое заведение

```
[Эмодзи-крючок] [Живой заголовок: название + конкретный повод для читателя]

[Название] [открылись/запустили/обновились] — [1 фраза, чем цепляет место].

[2–3 предложения: что внутри, атмосфера, что попробовать/на что смотреть. Личное впечатление, если было. Тон — «советую подруге», а не пресс-релиз]

📍 Адрес: [адрес]
🕒 Режим работы: [часы]
💰 Средний чек / цены: [если уместно]
🔗 [соцсети/сайт/бронь]

[Финальная фраза-действие: «Отправляйте тому, с кем пойдёте» / «Уже успели заглянуть?» / мини-голосование реакциями]

#[кафе/рестораны]
```

## 🏙 Городская новость

```
[Эмодзи] [Суть новости в одной строке]

[2–4 предложения: что произошло, когда, кого касается, почему это важно для минчан]

[Если есть — конкретное действие для читателя: где узнать больше, как это повлияет на маршруты/жизнь/планы]

Источник: [ссылка/упоминание источника — для внутреннего трекера обязательно, в тексте поста по ситуации]
```

## 🇧🇾 Белорусский бренд

```
[Эмодзи] [Живой заголовок: что бренд сделал и почему это интересно]

[Название бренда] [запустили/сделали/объединились с...] — [что именно].

[История/фишка бренда в 2–3 предложениях: чем отличаются, что интересного в продукте/подходе, почему хочется обратить внимание]

📍 Где найти: [магазин/сайт/маркетплейс]
💰 Цены: [диапазон]

[Дружеский финал: «Какую бы примерили/заказали?» / «Поддержим локальное?» / реакции]

#бренды #[одежда/обувь/сумки/аксессуары]
```

```

1. [Название] — [1 строка сути: чем хорош, для кого, когда идти]
2. [Название] — [1 строка сути]
3. [Название] — [1 строка сути]
4. [Название] — [1 строка сути]
5. [Название] — [1 строка сути]

[Финал: «Сохраняйте, пригодится» / «Отправляйте тому, кто снова спрашивает “ну куда пойдём?”» / «А что бы добавили вы?»]

#[основной_тег] #[дополнительный_тег]
```

## 📋 Компактная подборка в цитатном блоке

Использовать для быстрых Telegram-подборок, где важно дать много вариантов без длинных описаний.

Структура:

```
[Заголовок-вопрос + эмодзи]

[1 короткая подводка: что собрали и зачем]

> 1. [Название] — [2–6 слов сути]
>
> 2. [Название] — [2–6 слов сути]
>
> 3. [Название] — [2–6 слов сути]
>
> ...

[Финал: «Отправляйте тому, с кем...» / «Сохраняйте...»]

#[основной_тег] #[дополнительный_тег]
```

Правила:

- описания максимально короткие;
- названия мест выделяются визуально (жирным/цветом при верстке в Telegram);
- список можно оформить цитатным блоком;
- не объяснять каждое место абзацем;
- финал — короткий и дружеский.

Пример:

```
Куда идти в непогоду в Минске? 🌧

Собрали 10 мест, где можно переждать серость и классно провести время.

> 1. Чайная церемония — тихий дзен
>
> 2. Yoga Place — спокойная практика и растяжка
>
> 3. Kalilaska Market — винтажная барахолка

💌 Отправляйте тому, с кем будете прятаться от дождя!

#развлечения #музеи
```

## 🧑‍🎨 Локальный проект / ремесленник

```
[Эмодзи] [Имя/название проекта] — [суть в одной строке]

[История в 3–4 предложениях: как начинали, что делают особенного, почему это классно]

Где найти/купить/посмотреть: [ссылка/адрес]

[Финал с поддержкой: «Локальное — это всегда повод»]
```
