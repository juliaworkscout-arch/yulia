# Шаблоны постов для Telegram

## Общая формула поста ПОВОД

Пишем так, будто советуем подруге: «смотри, что нашли, вот почему это классно, вот куда идти, вот сколько стоит, а теперь решай, с кем пойдёшь».

```
[Эмодзи] [Короткий живой заголовок]

[1 абзац: что случилось/что появилось — без официоза, с ощущением находки]

[1 абзац: почему это повод — что попробовать, за чем идти, какой вайб, кому подойдёт]

[Конкретика: адрес / дата / цена / ссылка / бронь]

[Дружеский финал: вопрос, призыв отправить другу, мини-голосование реакциями]
```

Правило: в конце почти всегда должно быть маленькое действие — сохранить, отправить, выбрать реакцию, написать в комментариях или перейти по ссылке.

## 🆕 Новое заведение

```
[Эмодзи-крючок] [Живой заголовок: не просто название, а зачем читателю это интересно]

[Название] [открылись/запустили/обновились] — [1 фраза, чем цепляет место].

[2–3 предложения: что внутри, атмосфера, что попробовать/на что смотреть. Личное впечатление, если было. Тон — «советую подруге», а не пресс-релиз]

📍 Адрес: [адрес]
🕒 Режим работы: [часы]
💰 Средний чек / цены: [если уместно]
🔗 [соцсети/сайт/бронь]

[Финальная фраза-действие: «Отправляйте тому, с кем пойдёте» / «Уже успели заглянуть?» / мини-голосование реакциями]
```

## 🏙 Городская новость

```
[Эмодзи] [Суть новости в одной строке]

[2–4 предложения: что произошло, когда, кого касается, почему это важно для минчан]

[Если есть — конкретное действие для читателя: где узнать больше, как это повлияет на маршруты/жизнь/планы]

Источник: [ссылка/упоминание источника — для внутреннего трекера обязательно, в тексте поста по ситуации]
```

## 🇧🇾 Белорусский бренд

```
[Эмодзи] [Живой заголовок: почему бренд — повод, а не просто «знакомьтесь»]

[Название бренда] [запустили/сделали/объединились с...] — [что именно].

[История/фишка бренда в 2–3 предложениях: чем отличаются, что интересного в продукте/подходе, почему хочется обратить внимание]

📍 Где найти: [магазин/сайт/маркетплейс]
💰 Цены: [диапазон]

[Дружеский финал: «Какую бы примерили/заказали?» / «Поддержим локальное?» / реакции]
```

## 📋 Подборка

```
[Заголовок-крючок, например: «5 мест, где отметить день рождения и не разориться»]

1. [Название] — [1 строка сути: чем хорош, для кого, когда идти]
2. [Название] — [1 строка сути]
3. [Название] — [1 строка сути]
4. [Название] — [1 строка сути]
5. [Название] — [1 строка сути]

[Финал: «Сохраняйте, пригодится» / «Отправляйте тому, кто снова спрашивает “ну куда пойдём?”» / «А что бы добавили вы?»]
```

## 🧑‍🎨 Локальный проект / ремесленник

```
[Эмодзи] [Имя/название проекта] — [суть в одной строке]

[История в 3–4 предложениях: как начинали, что делают особенного, почему это классно]

Где найти/купить/посмотреть: [ссылка/адрес]

[Финал с поддержкой: «Локальное — это всегда повод»]
```

## 💬 Вовлечение (опрос/вопрос)

```
[Провокационный или простой вопрос по теме недели]

[Опция для голосования / призыв написать в комментариях]

[Лёгкий, разговорный тон — здесь уместнее всего самоирония про город]
```

## 📆 Дайджест недели

```
Итоги недели в Минске 🗓

— [Пункт 1: главный инфоповод недели]
— [Пункт 2]
— [Пункт 3]

Что сохраняли чаще всего: [ссылка на топ-пост]

Хороших выходных, увидимся на следующей неделе с новыми поводами 👋
```
