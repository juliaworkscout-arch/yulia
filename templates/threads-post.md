# Шаблон поста в Threads

## Логика

Threads — самый разговорный канал: короткая мысль/наблюдение/реакция, без официоза, с явным авторским голосом. Ссылка на подробности — не в самом посте, а в первом комментарии.

## Структура поста

```
[Одна мысль в 1–3 предложениях: наблюдение, реакция на инфоповод, вопрос к аудитории или личное мнение редакции]

[Опционально: лёгкая самоирония или вопрос, провоцирующий ответ в комментариях]
```

## Первый комментарий

```
Подробности тут → [ссылка на Telegram-пост]
```

## Примеры затравок

- «Минск в очередной раз доказывает, что повод найдётся даже во вторник — сегодня это [что-то новое]».
- «Если ты ещё не был в [место], то у нас для тебя вопрос: чем ты вообще занимаешься по вечерам?»
- «Локальный бренд недели, который заслуживает больше внимания, чем получает».

## Чек-лист

- [ ] Текст не является копипастой Telegram-версии — адаптирован под короткий разговорный формат
- [ ] Ссылка на подробности добавлена в первый комментарий сразу после публикации
- [ ] Пройден факт-чек, если пост содержит конкретный инфоповод/факт
